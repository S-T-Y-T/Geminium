# Geminium

Цифровой тренажёр управления производством экипировки для тхэквондо на основе цифрового двойника и ИИ.

Игрок руководит фабрикой в Узбекистане:
- закупает сырьё и производит добоки, шлемы и защиту;
- продаёт в розницу и по тендерам федераций;
- конкурирует с ИИ-компаниями Daebo и Abıdas.

Технологии цифровизации покупаются внутри игры, а их экономический эффект измеряет Лаборатория сценариев.

Проект — платформа выпускной квалификационной работы «Sport inventarlari işlab çiqarişda SI va raqamli egizaklar samaradorligini baholaş (Özbekiston misolida)». Защита — июнь 2027.

## Быстрый старт

1. Unity Hub → Add project from disk → папка проекта. Нужен редактор **Unity 6000.6.0f1**.
2. Откройте `Assets/Geminium/Scenes/Debug.unity` и нажмите ▶. На экране видны дата, скорость, компании, экономика и цены сырья.
3. Тесты: Window → General → Test Runner → EditMode → Run All.

Пошагово, для тех, кто впервые в Unity — [Docs/UNITY_GUIDE.md](Docs/UNITY_GUIDE.md).

## Лаборатория сценариев

Прогон стандартной партии без графики: игрок-бот, Daebo и Abıdas.

- **Из редактора:** меню **Geminium → Прогон без графики (36 месяцев)**. CSV сохраняется в `Reports/`.
- **Из командной строки** (редактор должен быть закрыт):

  ```
  "C:\Program Files\Unity\Hub\Editor\6000.6.0f1\Editor\Unity.exe" -batchmode -nographics -projectPath . ^
    -executeMethod Geminium.EditorTools.GeminiumTools.RunLabFromCommandLine ^
    -geminiumSeed 1 -geminiumMonths 36 -geminiumOut Reports\lab.csv -quit
  ```

CSV рассчитан на русский Excel: разделитель «;», десятичная запятая. Строка — компания и месяц. Колонки: макроэкономика, P&L, баланс, капитализация, выпуск, продажи, доли рынка, биржевые цены сырья. Одинаковый seed даёт одинаковый результат.

Тесты из командной строки:

```
Unity.exe -batchmode -nographics -projectPath . -runTests -testPlatform EditMode -testResults Reports\tests.xml
```

## Как устроен код

```
Assets/Geminium/
  Core/    ядро симуляции, чистый C# без UnityEngine — работает и в игре, и без графики
    Time/        игровое время, календарь, смены, темп
    Data/        описания данных, валидатор, каталог
    Companies/   компания, журнал денег, запасы, команды, контроллеры
    Economy/ Supply/ Production/ Market/ Warehouse/ Finance/   подсистемы
    Lab/         скриптовые боты, прогон, выгрузка CSV
    Formulas.cs  формулы GDD как чистые функции
  Game/    связь с Unity: файл данных GameDatabase, отладочная сцена
  Editor/  меню Geminium
  Data/    GameDatabase.asset — все числа игры (правятся в инспекторе)
  Scenes/  Debug.unity
  Tests/   EditMode-тесты
```

Принципы:
- **Минута — шаг.** Симуляция идёт шагами по одной игровой минуте. Подсистемы вызываются в фиксированном порядке: контроллеры → экономика → снабжение → производство → рынок → склад → финансы.
- **Детерминизм.** Вся случайность — из одного seed с именованными потоками.
- **Решения — команды.** Любое решение компании (цена, план, закупка, кредит, станок) подаётся командой. Её проверяют сразу и применяют до расчёта ближайшей минуты. Игрок и боты действуют по одним правилам.
- **Числа — в данных.** Все числа живут в `GameDatabase.asset`. Сейчас это заглушки, их калибруют по данным главы 2 ВКР.
