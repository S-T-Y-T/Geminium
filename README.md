# Geminium

Цифровой тренажёр управления производством экипировки для тхэквондо на основе цифрового двойника и ИИ.

Игрок руководит фабрикой в Узбекистане:
- закупает сырьё и производит добоки, шлемы и защиту;
- продаёт в розницу и по тендерам федераций;
- конкурирует с ИИ-компаниями Daebo и Abıdas.

Технологии цифровизации покупаются внутри игры, а их экономический эффект измеряет Лаборатория сценариев.

Проект — платформа выпускной квалификационной работы «Sport inventarlari işlab çiqarişda SI va raqamli egizaklar samaradorligini baholaş (Özbekiston misolida)». Защита — июнь 2027.

## Состояние

**Готовы этапы 1 «ядро симуляции», 2 «пространственный цех» и 3 «сбыт, маркетинг, боты»** (ноябрь 2026). Что работает:
- экономика целиком: ИИ-ядро (циклы, инфляция, ключевая ставка, события), снабжение, рынок B2C, склад, финансы с кредитами и налогами;
- цех на сетке: зоны, проходы, станки трёх уровней, стеллажи; разнорабочие возят грузы по маршрутам;
- персонал с рынка труда: опыт, усталость, мораль, смены, переработки; износ, поломки и ТО; ОТК и политика брака;
- аналитика цеха: диаграмма спагетти, такт, загрузка станков, узкое место;
- B2B-тендеры федераций с контрактами, неустойками и рекламациями; маркетинг (реклама, турниры, спонсорство, амбассадоры, сертификация) и живая репутация;
- конкуренты трёх архетипов: сами строят цех, решения ищут восхождением (алгоритм ТЗ) или принимают обученной нейросетью (ML-Agents, PPO на суррогатной модели цеха с дообучением на полном цехе);
- прогон без графики с выгрузкой KPI в CSV и сравнение скриптовых ботов с нейросетью;
- отладочная сцена с видом цеха и редактором планировки;
- ветка «Цифровизация» из 7 модулей (IoT, предиктивное ТО, цифровой двойник, ИИ-раскрой, ИИ-контроль, прогноз спроса, ИИ-цены) и Лаборатория сценариев с ROI, сроком окупаемости и NPV;
- 117 автоматических тестов.

Идёт этап 4: готовы цифровизация и Лаборатория сценариев; дальше — сохранения и кампания, экраны и языки, LLM. План и статус задач — [TODO.md](TODO.md).

## Быстрый старт

1. Unity Hub → Add project from disk → папка проекта. Нужен редактор **Unity 6000.6.0f1**.
2. Откройте `Assets/Geminium/Scenes/Debug.unity` и нажмите ▶. В центре — цех выбранной компании (WASD — камера, колесо — масштаб), слева — сводка, сверху — дата, скорость, компании, «Спагетти» и «Редактировать».
3. Тесты: Window → General → Test Runner → EditMode → Run All.

Пошагово, для тех, кто впервые в Unity — [Docs/UNITY_GUIDE.md](Docs/UNITY_GUIDE.md).

## Лаборатория сценариев

Главный инструмент для глав 3.2–3.3 ВКР: одна и та же фабрика прогоняется с разными модулями цифровизации, эффект каждого сравнивается с базой на тех же seed.

- **Из редактора:** меню **Geminium → Лаборатория сценариев (5 seed × 36 месяцев)**. Результат — `Reports/scenarios_summary.csv`: эффект на прибыль в месяц, 95%-й интервал, ROI, срок окупаемости, NPV и изменение KPI; каждый прогон — в `Reports/scenarios_runs.csv`.
- **Из командной строки:** `-executeMethod Geminium.EditorTools.GeminiumTools.RunScenariosFromCommandLine -geminiumSeeds 10 -geminiumMonths 36 -quit`.
- Сценарии задаются в данных: `GameDatabase` → `Data → Scenarios` (модули, госпрограмма, база для сравнения).

Простой прогон стандартной партии без графики (игрок-бот, Daebo и Abıdas) с полным набором KPI по месяцам:

- **Из редактора:** меню **Geminium → Прогон без графики (36 месяцев)**. CSV сохраняется в `Reports/`.
- **Из командной строки** (редактор должен быть закрыт):

  ```
  "C:\Program Files\Unity\Hub\Editor\6000.6.0f1\Editor\Unity.exe" -batchmode -nographics -projectPath . ^
    -executeMethod Geminium.EditorTools.GeminiumTools.RunLabFromCommandLine ^
    -geminiumSeed 1 -geminiumMonths 36 -geminiumOut Reports\lab.csv -quit
  ```

CSV рассчитан на русский Excel: разделитель «;», десятичная запятая. Строка — компания и месяц. Колонки: макроэкономика, P&L, баланс, капитализация, выпуск, продажи, доли рынка, логистика, простои, брак и возвраты, персонал, биржевые цены сырья. Одинаковый seed даёт одинаковый результат.

Тесты из командной строки:

```
Unity.exe -batchmode -nographics -projectPath . -runTests -testPlatform EditMode -testResults Reports\tests.xml
```

## Как устроен код

```
Assets/Geminium/
  Core/    ядро симуляции, чистый C# без UnityEngine — работает и в игре, и без графики
    Time/        игровое время, календарь, смены, темп
    Data/        описания данных, валидатор, каталог
    Companies/   компания, журнал денег, запасы, команды, контроллеры
    Factory/     сетка цеха, поиск пути, стартовая планировка
    Staff/       сотрудники и рынок труда
    Economy/ Supply/ Production/ Market/ Warehouse/ Finance/   подсистемы
    Sales/       тендеры, маркетинг, турниры, репутация
    Digital/     модули цифровизации, цифровой двойник
    Lab/         боты (поиск восхождением и политика), прогон, Лаборатория сценариев, выгрузка CSV
      Surrogate/ суррогатная модель цеха: формулы, калибровка, быстрый мир для обучения
    Formulas.cs  формулы GDD как чистые функции
  Game/    связь с Unity: файл данных GameDatabase, отладочная сцена, отрисовка цеха (FloorView)
  ML/      ML-Agents: агент, площадки обучения, ONNX-политика (Inference Engine), обученная модель
  Editor/  меню Geminium: Лаборатория, снимок цеха, калибровка суррогата, сборка среды обучения, сравнение ботов
  Data/    GameDatabase.asset — все числа игры (правятся в инспекторе)
  Scenes/  Debug.unity
  Tests/   EditMode-тесты
```

Принципы:
- **Минута — шаг.** Симуляция идёт шагами по одной игровой минуте. Подсистемы вызываются в фиксированном порядке: экономика → персонал → маркетинг → тендеры → контроллеры → снабжение → производство → рынок → склад → финансы.
- **Детерминизм.** Вся случайность — из одного seed с именованными потоками.
- **Решения — команды.** Любое решение компании (цена, план, закупка, кредит, планировка цеха, найм, заявка на тендер, реклама) подаётся командой. Её проверяют сразу и применяют до расчёта ближайшей минуты. Игрок и боты действуют по одним правилам.
- **Числа — в данных.** Все числа живут в `GameDatabase.asset`. Сейчас это заглушки, их калибруют по данным главы 2 ВКР.
