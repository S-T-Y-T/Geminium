# Geminium

Симулятор-тренажёр фабрики экипировки для тхэквондо на Unity 6 (6000.6, URP 2D). Это платформа для ВКР автора «Sport inventarlari işlab çiqarişda SI va raqamli egizaklar samaradorligini baholaş (Özbekiston misolida)». Защита — июнь 2027, потом развитие в докторскую.

## Работа с автором

- Общение на русском.
- Автор почти не знает C# и Unity. Весь код пишет Claude: объясняет сделанное простыми словами и в конце этапа даёт маленькое практическое задание.
- Имена в коде — на английском, комментарии — на русском.

## Правила архитектуры

- Ядро симуляции — чистый C# в asmdef с `noEngineReferences`. Оно запускается без графики для Лаборатории сценариев и обучения ботов.
- Вся случайность идёт через один RNG с seed: одинаковый seed даёт одинаковый результат.
- Числовые параметры хранятся в данных (ScriptableObject/JSON).
- Тексты интерфейса — через таблицы локализации uz / ru / en. Узбекский — на новом алфавите 2026 года (Ş, Ç, Ö, Ğ).
- Компанией управляет контроллер: игрок, бот, позже удалённый игрок. Все компании живут по одним правилам.
- Графика своя: плоский вектор, вид сверху 3/4.
- Дата фиксирована, объём гибкий: заморозка функций 1 мая 2027; порядок сокращения — в `TODO.md`.
