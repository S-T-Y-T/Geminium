# Данные Geminium

`GameDatabase.asset` — все данные игры в одном файле:
- сырьё;
- станки;
- продукты с рецептами;
- профессии;
- календарь;
- график работы по умолчанию;
- темп игры.

Откройте файл в Unity: в инспекторе появятся списки, числа меняются прямо там, без правки кода. Если данные сломаны (например, рецепт ссылается на несуществующее сырьё), в Console появится жёлтое предупреждение `GameDatabase: ...`.

**Id** — латинские строчные буквы, цифры и `_` (например, `eva_foam`). Из Id строится ключ перевода (`material.eva_foam`), поэтому названий на русском здесь нет.

**Числа-заглушки.** Цены, зарплаты, спрос и времена операций — правдоподобные значения для старта. Их нужно откалибровать по данным главы 2 ВКР.

Как описаны поля — в `Assets/Geminium/Core/Data/Definitions.cs`.
